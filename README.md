# PennyPlan
PennyPlan is a clean, analytics-focused budgeting dashboard that helps users track income, spending, and savings trends over time. It features interactive charts, category breakdowns, and a searchable transaction table. Designed for clarity and insight, PennyPlan makes personal finance tracking simple, visual, and data-driven.

Key Features

User Authentication – Secure login and account creation for personalized budgeting.

Cloud Database Integration – Store, retrieve, update, and delete financial transaction data in real time.

Spending Visualizations – Interactive charts and graphs to help users understand their spending habits.

Budget Goal Setting – Create monthly category budgets (e.g., $400 per month on groceries or entertainment).

Smart Spending Feedback – Automatic insights and comparisons, such as: “You spent 22% more on entertainment this month than last month.”

Historical Tracking & Exporting – View past months’ data and export transaction history as a CSV file for further analysis.
